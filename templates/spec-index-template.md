# Spec 索引

> 本项目全部 Spec 的目录。放在 `docs/spec/INDEX.md`。
> `PLAN.md` 只挂当前活跃的 Spec 链接，全量目录看这里。

| spec_id | 标题 | status | version | parent | 路径 |
|---|---|---|---|---|---|
| SPEC-001 | | Frozen | 1 | - | `docs/spec/xxx.md` |
| SPEC-002 | | Draft | 1 | SPEC-001 | `docs/spec/xxx-sub.md` |

## 状态说明

| 状态 | 允许的动作 |
|---|---|
| Draft | 自由编辑；不能作为实施或验收完成的依据 |
| Frozen | 可以拆 Issue、进入实施 |
| Verified | P0/P1 验收项都有通过证据 |
| Superseded | 只读，必须指向后继 Spec |
